Dein Shopware-Shop – live auf dem Elgato Stream Deck

Der Stream Deck Companion macht die wichtigsten Kennzahlen deines Shopware-6-Shops in Echtzeit auf deinem Elgato Stream Deck sichtbar. Tagesumsatz, letzte Bestellung, Live-Shop-Status – alles auf einen Blick und auf Knopfdruck, ohne ständig das Admin-Backend offen zu haben.

Das Companion-Plugin ist komplett kostenlos und Open Source (MIT). Es stellt deinem Stream Deck Plugin gebündelte, performante Auswertungs-Endpoints bereit – abgesichert über einen shop-gebundenen API-Key, den du selbst im Admin verwaltest.

Diese Datenpunkte liefert das Companion

  • Tagesumsatz inklusive Vergleich zum Vortag
  • Letzte Bestellung in Echtzeit (Nummer, Kunde, Betrag)
  • Top-Bestellung & Top-Produkt des Tages
  • Durchschnittlicher Bestellwert (AOV)
  • Umsatzverlauf der letzten 7 bis 60 Tage
  • Umsatz pro Stunde für den heutigen Tag
  • Live-Shop-Status: Produktivmodus, Systemzustand, überfällige geplante Aufgaben

Über die Plugin-Konfiguration legst du fest, welche Bestell- und Zahlungsstatus in die Auswertungen einfließen – so passt der Umsatz exakt zu deiner Definition.

Kostenlos, quelloffen und datensparsam

  • 100 % kostenlos im Shopware Store, ohne Funktions-Einschränkung
  • Quelloffen unter MIT-Lizenz
  • Kein externer Lizenzserver, kein Tracking. Der API-Key ist ein shop-gebundenes Shared Secret und schützt ausschließlich deine eigenen Endpoints
  • Mehrere API-Keys pro Shop möglich – ein eigener Key je Stream Deck

In 2 Minuten startklar

  1. Plugin installieren & aktivieren
  2. In der Plugin-Konfiguration unter „API-Zugang" einen API-Key generieren
  3. Den Key im Stream Deck Plugin eintragen – fertig

Die Administrations-Oberfläche ist nach der Installation sofort einsatzbereit – kein zusätzlicher Build-Schritt auf deinem Shop nötig.

Volle Power mit dem Stream Deck Plugin

Dieses Companion-Plugin ist der kostenlose Gegenpart zum Stream Deck Plugin von AS Business Solutions, das du im Elgato Marketplace erhältst. Zusammen verwandeln sie deine Elgato-Hardware in ein physisches Cockpit für deinen Shopware-Shop. Das Companion allein liefert bereits die Daten – das Stream Deck Plugin bringt sie auf die Tasten.

Systemvoraussetzungen

  • Shopware 6.6 oder 6.7
  • PHP 8.2 oder höher
