Installation

  1. Erweiterung im Shopware-Admin unter Einstellungen → System → Erweiterungen → My Extensions installieren und aktivieren.
  2. Plugin-Konfiguration öffnen und unter der Karte „API-Zugang" einen API-Key generieren. Der Schlüssel wird aus Sicherheitsgründen nur einmal angezeigt – kopiere ihn sofort.
  3. Den Key im Stream Deck Plugin (Elgato Marketplace) im Feld „Companion API key" eintragen.

Die Administrations-Oberfläche ist sofort einsatzbereit – ein zusätzlicher Build-Schritt auf dem Shop ist nicht nötig. Optional kann der Key auch per Konsole erzeugt werden: bin/console asbs:streamdeck:key:create.
