Installation

  1. Install and activate the extension in the Shopware admin under Settings → System → Extensions → My Extensions.
  2. Open the plugin configuration and generate an API key on the “API access" card. For security the key is shown only once – copy it right away.
  3. Paste the key into the Stream Deck plugin (Elgato Marketplace) in the “Companion API key" field.

The administration UI is ready immediately – no extra build step on the shop is required. Optionally the key can also be created via console: bin/console asbs:streamdeck:key:create.
