Your Shopware store – live on the Elgato Stream Deck

The Stream Deck Companion surfaces the most important metrics of your Shopware 6 store in real time on your Elgato Stream Deck. Daily revenue, the latest order, live shop status – all at a glance and at the press of a key, without keeping the admin backend open all day.

The companion plugin is completely free and open source (MIT). It exposes bundled, performant analytics endpoints to your Stream Deck plugin, secured by a shop-bound API key that you manage yourself in the admin.

Data points the companion delivers

  • Daily revenue including a day-over-day comparison
  • Latest order in real time (number, customer, amount)
  • Top order & top product of the day
  • Average order value (AOV)
  • Revenue trend for the last 7 to 60 days
  • Revenue per hour for the current day
  • Live shop status: production mode, system health, overdue scheduled tasks

In the plugin configuration you decide which order and payment states feed the analytics – so revenue matches exactly your own definition.

Free, open source and privacy-friendly

  • 100% free in the Shopware Store, with no feature limits
  • Open source under the MIT license
  • No external license server, no tracking. The API key is a shop-bound shared secret that only protects your own endpoints
  • Multiple API keys per shop – one key per Stream Deck

Ready in two minutes

  1. Install & activate the plugin
  2. Generate an API key under “API access" in the plugin configuration
  3. Paste the key into the Stream Deck plugin – done

The administration UI is ready right after installation – no extra build step on your shop required.

Full power with the Stream Deck plugin

This companion plugin is the free counterpart to the Stream Deck plugin by AS Business Solutions, available on the Elgato Marketplace. Together they turn your Elgato hardware into a physical cockpit for your Shopware store. The companion provides the data – the Stream Deck plugin brings it to your keys.

System requirements

  • Shopware 6.6 or 6.7
  • PHP 8.2 or higher
